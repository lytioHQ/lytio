{

  "metrics": [

    {
      "title": "<finding title>",
      "description": "<detailed explanation>",
      "confidence": "<high|medium|low>",
      "evidence": {
        "source_sheet": "<sheet name>",

        "source_columns": ["<column names>"],
        "source_rows": "<row description, e.g. Rows 2-45>",
        "reason": "<which numbers/rows/columns support this conclusion>",
        "confidence": "<high|medium|low>"
      }
    }
  ],
  "risks": [
    {
      "title": "<risk title>",
      "description": "<detailed explanation>",
      "severity": "<critical|high|medium|low>",
      "evidence": {
        "source_sheet": "<sheet name>",
        "source_range": "<cell range>",
        "source_columns": ["<column names>"],
        "source_rows": "<row description>",
        "reason": "<which numbers/rows/columns support this risk>",
        "confidence": "<high|medium|low>"
      }
    }
  ],
  "recommendations": [
    {
      "title": "<recommendation title>",
      "description": "<actionable steps>",
      "priority": "<high|medium|low>",

        "source_sheet": "<sheet name>",

  "executive_summary": {
    "content": "<2-3 paragraph executive summary>"
  }

## Rules
- Provide 3-5 insights, 2-4 risks, 3-5 recommendations, 3-5 metrics.
- Every insight, risk and recommendation MUST include an evidence object that cites the actual sheet, cell range, columns, rows and numbers from the dataset.
- Never fabricate numbers. If evidence is weak or a number cannot be verified, lower the confidence level instead of guessing.
- Business health score must reflect overall data quality and performance (0-100).

- Return ONLY the JSON object. No markdown fences, no explanations.
